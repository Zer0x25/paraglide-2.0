## 2024-03-24 - Accessibility on Icon-only Buttons
**Learning:** Native `disabled` on standard HTML `<button>` correctly exposes state to assistive tech. Explicitly adding `aria-disabled` alongside native `disabled` in a React standard `<button>` is redundant but non-breaking. Focus should remain on adding `aria-label` to icon-only buttons since it provides the core identifying information.
**Action:** Always add `aria-label` to icon-only interactive elements like close headers. Rely on native `disabled` when using HTML `<button>` rather than adding dual `aria-disabled` properties unless the element needs to remain focusable while disabled.
